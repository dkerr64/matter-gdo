# Matter Garage Door Closure

This example creates a Matter Closure device for a garage door using the esp_matter component downloaded from the [Espressif Component Registry](https://components.espressif.com/) instead of the extra component in local, so the example can work without setting the esp-matter environment.

See the [docs](https://docs.espressif.com/projects/esp-matter/en/latest/esp32/developing.html) for more information about building and flashing the firmware.

## Prerequisites

- **IDF version**: v5.5.5
